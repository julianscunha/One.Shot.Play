# ADR-001: Arquitetura Back4App + MongoDB

## Status
Aceito

## Data
2026-08-17

## Contexto
Precisamos de uma aplicação web profissional rodando em servidor público, preferencialmente free tier, com banco de dados gerenciado.

## Decisão
Usar Back4App free tier com Express.js e MongoDB.

## Alternativas Consideradas

### Vercel + PostgreSQL
- Prós: Ótima DX, serverless
- Contras: Free tier limitado, Cold starts, MongoDB não nativo

### Railway
- Prós: Free tier generoso
- Contras: Instabilidade recente, limites mais baixos

### Back4App
- Prós: Free tier estável, MongoDB nativo, HTTPS incluso, fácil deploy
- Contras: Workers limitados, mas suficiente para nosso uso

## Consequências
- Express + MongoDB como stack principal
- Deploy simplificado via CLI ou GitHub Actions
- HTTPS gerenciado pelo Back4App
- Dependência de MongoDB Atlas (gerenciado)
