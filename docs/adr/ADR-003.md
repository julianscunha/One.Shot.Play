# ADR-003: Pipeline em Fases com Checkpoint

## Status
Aceito

## Data
2026-08-17

## Contexto
Precisamos de resiliência no processo de geração de vídeo, permitindo retry por fase sem recomeçar do zero.

## Decisão
Implementar pipeline com fases sequenciais, cada uma com checkpoint no banco.

## Alternativas Consideradas

### Pipeline atômico
- Prós: Simples
- Contras: Falha = recomeçar tudo

### Pipeline paralelo
- Prós: Performance
- Contras: Complexidade alta, difícil retry

### Pipeline sequencial com checkpoint (Escolhido)
- Prós: Resiliência, retry por fase, simplicidade
- Contras: Mais lento que paralelo

## Consequências
- 7 fases: estratégia → script → áudio → imagens → vídeo → legenda → upload
- Estado salvo no banco após cada fase
- Retry exponencial (10s/20s/40s... até 10min)
- Cancelamento a qualquer momento
