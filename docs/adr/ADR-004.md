# ADR-004: Templates como Snapshots

## Status
Aceito

## Data
2026-08-17

## Contexto
Usuário quer trocar templates sem afetar agendamentos existentes.

## Decisão
Agendamentos armazenam snapshot do template no momento da criação.

## Alternativas Consideradas

### Referência dinâmica
- Prós: Economia de espaço
- Contras: Mudança no template afeta agendamentos

### Snapshot (Escolhido)
- Prós: Isolamento total, previsível
- Contras: Mais espaço em disco

## Consequências
- Template pode ser editado sem afetar agendamentos
- Cada agendamento tem sua própria cópia das configurações
- Histórico preservado
