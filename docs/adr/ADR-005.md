# ADR-005: pt-BR como Idioma Padrão

## Status
Aceito

## Data
2026-08-17

## Contexto
Usuário brasileiro, todo o sistema deve ser em português.

## Decisão
Todo o sistema (interface, documentação, logs, alertas, código) usa pt-BR.

## Alternativas Consideradas

### Inglês
- Prós: Padrão técnico
- Contras: Usuário não é fluente

### pt-BR (Escolhido)
- Prós: Melhor UX para usuário brasileiro
- Contras: Código menos internacionalizável

## Consequências
- Variáveis em inglês (padrão técnico)
- Comentários em pt-BR
- Interface 100% em pt-BR
- Documentação em pt-BR
